# GA遅れ−基軸遅れと、オフセット不整合の直接比較

今回の比較対象はY=D_GA-Bのみ。停止位置・車群分裂の分析には広げていない。

- D_GA：既存20路線のGA最良発見遅れ。大域最適値とは断定しない。
- B：基軸遅れ。B(0)=0、B(j)=max_{i<j}[B(i)+delta_ij]で計算。
- R0：非隣接を含む全ペアの最適オフセット範囲への円周距離の最小合計。
- Rw：同じ違反量をdmax-dminで重み付けした最小合計。

20路線×13速度=260条件。R0・Rwは全条件で数値許容誤差内の最小値を確認済み（詳細は更新版Offset_Incompatibility_20_Corridors.zip）。

## 結果

|対象|R0とのPearson相関|RwとのPearson相関|
|---|---:|---:|
|全260条件を合算|0.583|0.457|
|各路線の平均を差し引いた速度変化|0.139|-0.137|

全体では正の相関があるが、同一路線で速度を変えたときの残差の増減をうまく捉えているとはまだ言えない。路線別の相関はper_corridor_correlations.csvと03の図を参照。

R0=Rw=0の条件が39あり、そのうち22条件ではD_GA-Bも数値誤差内で0。残差が1秒を超えるのは12条件、最大8.88秒。不整合ゼロでも総遅れが正であることと、不整合ゼロでも基軸からの残差が正であることは区別する。

D_GA-Bは「基軸で説明しきれない部分」。基軸近似の誤差なども含むため、不整合が原因の遅れと同一視しない。
