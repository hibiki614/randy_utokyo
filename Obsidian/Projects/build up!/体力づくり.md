# 体力づくり Overview
- 5月目標 50km
	- 基本的には10km以内の軽いジョグと，10kmを時間測らずにって感じ．
	- 膝壊さんように，無理はしない．
	- 基本的には毎日(週5回)朝の傾斜ウォーキングをする．脂肪を落とさないといけないから．
	- 週に3回以上走る．10km走るか，筋トレしてから軽く走るか，って感じ．
- 6月
	- 6/27にハーフマラソンを入れました．
		- 目標は2時間切り
	- なかなか厳しいかも．キロ5分ってことなんで，10キロを50分で走れるようにすることが最初の目標だな．
	- 120キロは最低でも走りたいできれば150キロくらい
	- となると週に30キロ～40キロ(5-6kmを1本，10kmを2本，15km以上を1本って感じだね)
	- 5-6kmの日は筋トレしましょう．
	- 走らない日に筋トレ
- 7月
	- この時期から熱くなってくるけど，150キロは走らないと．
	- 10キロを40分で走れるようになっていると素晴らしい
		- 高校生のころに戻りたい
