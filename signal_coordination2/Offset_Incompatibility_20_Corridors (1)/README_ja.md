## ペア理論

Sakakibara & Oguchi (2025), Fundamental theory of coordination efficiency of signalized intersections on an arterial road, IATSS Research 49, 231–246. ユーザー提供PDFの式(15),(16),(20),(21),(25)を使用。

phiは正規化相対オフセット（周期1）、Lambda=Lij/(CV)、gi,gjは青時間率。RD=1-gi-gj+P。

h(z;gs,gd)=0 （z<gd-P または z>=1-gs+P）、RD*(z-gd+P)/P （gd-P<=z<gd）、1-gs-z+P （gd<=z<1-gs+P）。RD<=0なら全域ゼロ。

dij(phi)/C = {h((Lambda-phi)mod1;gi,gj)+h((Lambda+phi)mod1;gj,gi)}/2。

折れ線の全ブレークポイントを解析的に列挙し、最小値、最大値、最小値をとる集合を計算。細かい格子上の最小値で代用していない。計算内部では時間を周期で割って数値スケールをそろえ、指標の出力時に秒単位へ戻す。最適集合は円周上の弧の和として保持し、0/120秒をまたぐ範囲も一つの弧へ併合する。今回の6110ペア条件では最適集合は全て1つの円周弧だった（全域一定の場合を含む）。一般には2つの離れた弧も扱える。

全6110ペアについて従来の理論最小遅れと照合し、最大差は1.96e-14秒。各最適弧の両端・中心が最小遅れを与えることも確認。

## 不整合指標の定義

各ペアの最適相対オフセット集合をAijとする。

dist_C(xj-xi,Aij) は、周期C上で最適集合へ到達する最短距離。単位はオフセット秒。

R0* = min_x sum_{i<j} dist_C(xj-xi,Aij)

Rw* = min_x sum_{i<j} (dmax_ij-dmin_ij)*dist_C(xj-xi,Aij)

後者は遅れ秒ではなく、遅れ変動幅×オフセットずれの指標単位（形式的にはs²）。正確な追加遅れdij(phi)-dminを積分・合計したものではない。全域一定のペアは全オフセット最適なので、R0でもRwでも不整合に寄与しない。非隣接を含む全ペアを使用。辺数・交差点数の影響はグループ別・路線内比較で別途評価。

## 最小費用循環との関係と、周期処理

1. 最適弧と周期の整数シフトを固定すると、条件はl_ij<=xj-xi<=u_ijとなる。
2. その区間からのずれをt_ijとし、min sum a_ij*t_ij を線形計画で解く。a=1がR0、a=dmax-dminがRw。
3. これは上下限を2本の有向辺（費用u、-l、各容量a）とした最小費用循環の双対と同値。実装はSciPy/HiGHSのLPを解き、その双対から循環流を取り出している。専用の負閉路消去法コードではない。
4. 実装内部のtは区間への距離。上下限の両違反量の和と同じ最適目的値を与える。LP双対の流れは2辺の容量条件を満たす。
5. ただし周期シフトの選択まで含めた全問題が、そのまま一つの最小費用循環になるわけではない。

この5番を無視すると見かけの不整合を数えてしまうので、今回は周期を正しく扱った近似計算と検証計算を分けた。

### 高速計算（最小値の上界）

最適オフセット実績を使わず、ゼロ配置・順方向波・逆方向波・固定乱数3配置の計6初期値を使用。各ノードの循環区分線形距離を座標ごとに改善し、最近の弧/周期シフトを選択。その固定条件のLPを解いて、周期を再割当てする処理を反復。最良候補を採用。

この手順は最小費用循環と同値なLPを含むが、周期選択がヒューリスティックなので、一般には全体の大域最適性は保証されない。高速版の値はR*の実行可能な上界。

### 検証計算と定式化の強化

初回は各条件1秒のMILP検証でR0:197/260、Rw:202/260の証明にとどまった。今回、残る121条件について以下の同値変換・妥当な制約を追加した。

1. y_i = x_i/C + (g_i-g_0)/2 (mod 1) とし、青時間差による中心のずれを吸収。全ペアの中心が0または0.5になることを入力ごとに確認した。
2. この変換では全位相を反転しても目的値は同じなので、y_0=0、0<=y_1<=0.5に限定し、対称な配置の重複を除いた。これは最小値を変えない。
3. 三角形・四角形の閉路について、「中心の一周分の不整合は、最適範囲の半幅と違反量で吸収しなければならない」という妥当な不等式を追加した。閉路上の違反量の和は max(dist_1(sum signed centers,0)-sum halfwidths,0) 以上となる。これにより連続緩和の下限を強化した。閉路の違反量を目的関数で重複加算してはいない。
4. 周期整数変数を残したままMILPで最適性確認。最小費用循環1回だけで周期選択まで解けると主張していない。

## 再現方法

Python 3.10以降。依存関係：requirements.txt。

```sh
python -m pip install -r requirements.txt
python source/run_analysis.py --fast-only
python source/summarize.py
python source/validate.py
```

周期のMILP検証も行う場合：

```sh
python source/run_analysis.py --time-limit 1
python source/certify.py --time-limit 30
python source/summarize.py
python source/baseline_evaluation.py
```

実行すると既存の結果CSVを上書きするため、比較したい場合はフォルダをコピーして実行する。高速版の乱数シードは固定。MILPは時間制限のため、環境により証明数や下界が変わる。

GAの同一環境比較を再実行したい場合は、元GAコードの場所をbenchmark_ga.pyへ指定する。重い処理なので通常の指標再現には不要。

## 解釈

現時点では、重み付けによるメカニズム説明の成功とは言えない。S1+Rwによる小さな予測改善はあるが、Rwの係数は負で、共線性も強い。全条件で指標最小値を数値許容誤差内で確認済みだが、それは実交通遅れの大域最適性を意味しない。個別ペアの理論到着条件と実路線の車群の違い、非隣接区間の重複、感度を最大・最小差だけで表すことの妥当性が残る。


## 基軸遅れを使った基準値との比較

不整合単独は実遅れそのものを表さない。R0=Rw=0の39条件でもGA遅れは0～54.545秒/台。したがって不整合が小さいのに遅れが正であることを、そのまま指標の失敗とはしない。

全ペア最小遅れの和S1は区間を重複計上するので、D-S1を追加遅れと解釈するのも不適切。実際に260条件中257条件でD<S1となる。

比較用に、基軸の考え方によるB(j)=max_{i<j}(B(i)+delta_ij), B(0)=0を計算した。路線順に進む経路の理論最小遅れ和の最大値で、非隣接ペアも候補に含める。

このBとGA遅れDの相関は0.9571。今回の260条件ではD>=B（数値誤差内）だった。ただし、あらゆる路線・到着条件で厳密な下界になるという証明は与えていない。

D-Bを「基軸基準からの残差」として扱うと、R0との相関0.5832、Rwとの相関0.4571。同一路線内の平均を引いた残差との相関はR0:0.1392、Rw:-0.1368にとどまる。速度による残差変動の説明は依然弱い。

ただし残差には基軸近似の誤差・理想到着条件との差・GAの探索誤差も含まれ、不整合が原因の遅れと同一視しない。B自体と指標が相関することも考慮が必要。

路線丸ごと除外交差検証：BのみMAE7.1906秒、B+R0は7.2865秒、B+Rwは7.1146秒。追加指標による改善は小さく、Rwの係数はここでも負。残差との単純相関だけから独立した追加説明力があるとは結論しない。

基軸が支配的かどうかを議論する際、Bはペア区間の遅れであり、特定交差点で必ず停止することを直接示さない。最適解が複数ある場合、停止位置・方向別配分も変わり得る。基軸外の信号が与える影響を、別途比較する必要がある。
