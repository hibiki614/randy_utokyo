# 全体の主張

系統信号制御では、オフセットを調整することで遅れを減らす。  
しかし、オフセットを最適化しても、路線や速度によって最小遅れは大きく異なる。  
これは、サイクル長 (C)、リンク長 (L)、速度 (V) が作る位相条件、すなわち

[  
\Lambda=\frac{L}{CV}  
]

によって、そもそも遅れを減らしやすい条件と減らしにくい条件があるためではないか。

1リンク2交差点では、既往研究によって (\Lambda) とオフセット (x) から遅れを理論的に計算できる。  
一方、多交差点では車群分裂が生じるため、各リンクの理論遅れを単純に足し合わせても全体の遅れにはならない。  
そこで本研究では、1リンク2交差点の系統効果理論をもとに、多交差点路線の「遅れの発生しやすさ」を説明する特徴量を構築する。

# Slide 2. 系統信号制御とは

## 一言でいうと

**系統信号制御とは、複数信号の青開始タイミング、すなわちオフセットを調整して、車群の停止遅れを減らす制御である。**

## スライド内容

- 複数の信号交差点が共通のサイクル長 (C) で動く
    
- 各交差点の青開始時刻のずれをオフセット (x) と呼ぶ
    
- オフセットを調整して、上流から来る車群を下流の青時間に合わせる
    
- 目的は信号遅れ (d) の低減
    

図：

```text
time →
Signal 0   [ green ]------[ green ]------
              車群
                 \\\\\\\\\
Signal 1        [ green ]------[ green ]--
                    ↑ offsetを調整して青に合わせる
```

## 話すこと

系統信号制御では、複数の信号を一つの路線として見て、青時間のタイミングを調整する。  
うまく調整できると、車群が下流交差点でも青に到着し、停止遅れを減らせる。

# Slide 4. 実例：オフセットを最適化しても遅れは違う

## 一言でいうと

**実際にオフセットを総当たりで最適化しても、路線や速度によって最小遅れは大きく異なる。**

## スライド内容

図案A：

- 横軸：速度 (V)
    
- 縦軸：最適遅れ (d_{\mathrm{opt}})
    
- 複数路線の折れ線を重ねる
    

注記：

[  
d_{\mathrm{opt}}=\min_x d(x)  
]

強調すること：

- すべての点でオフセットは最適化済み
    
- 同じ速度でも路線によって遅れが違う
    
- 同じ路線でも速度によって遅れが変わる
    

## 話すこと

各 route-speed に対してオフセットは総当たりで最適化している。  
それでも最小遅れには大きな違いがある。  
つまり、オフセット以外の要因、特に (C,L,V) の組み合わせが、遅れの発生しやすさを左右している可能性がある。

# Slide 8. 既往研究：1リンク2交差点では遅れを理論的に計算できる

## 一言でいうと

この理論を使うと、ある (\Lambda) のもとでオフセットを変えたときの遅れを計算できる。

# Slide 9. 遅れの計算方法：待ち行列の面積

## 一言でいうと

**信号遅れは、累積到着・累積出発曲線の差、すなわち待ち行列長を時間で積分することで計算できる。**

## スライド内容

図：

累積曲線または時空間図から待ち行列を示す。

例：

```text
queue length
^
|        /\
|       /  \       ← 三角形・台形の面積 = 総遅れ
|______/____\________> time
```

または累積曲線：

```text
cumulative vehicles
^
| arrival   /
|          /
|         /____ departure
|        /   |
|_______/____|______> time
        面積 = total delay
```

説明：

- 赤で到着が止められると待ち行列が形成
    
- 待ち行列長 (Q(t)) を時間積分すると総遅れ  
    [  
    D=\int Q(t),dt  
    ]
    
- 車両数で割ると平均遅れ  
    [  
    d=\frac{D}{N}  
    ]
    

両方向で計算：

[  
d=\frac{d_{\mathrm{forward}}+d_{\mathrm{backward}}}{2}  
]

## 話すこと

遅れをどう計算しているかを知らない人もいるので、ここは丁寧に説明する。  
赤信号で車両が溜まると、待ち行列長が増える。  
その待ち行列長を時間方向に積分した面積が総遅れになる。  
本研究では、上り方向・下り方向それぞれで計算し、その平均を路線の遅れとして扱う。

# Slide 10. (\Lambda) によって hce/lce が現れる

## 一言でいうと

**1リンク2交差点の理論計算により、オフセットで遅れを小さくしやすい (\Lambda) と、小さくしにくい (\Lambda) が存在することが分かる。**

## スライド内容

図のイメージ：

横軸：オフセット (x)  
縦軸：遅れ (d)

これを (\Lambda) の数直線上に複数並べる。

```text
Λ →
  hce付近        lce付近        hce付近
  d              d              d
  ^              ^              ^
  |__/\__        |^^^^^|        |__/\__
  +----> x       +----> x       +----> x
```

示したいこと：

- hce：
    
    - あるオフセットを選べば遅れが小さくなる
        
- lce：
    
    - どのオフセットでも遅れを小さくしにくい
        

hce 条件式も入れる：

[  
\Lambda_{\mathrm{hce}}\in [0,\delta\Gamma] \quad (N=0)  
]

[  
\Lambda_{\mathrm{hce}}\in  
\left[  
\frac{N}{2}-\delta\Gamma,,  
\frac{N}{2}+\delta\Gamma  
\right]  
\quad (N\geq 1)  
]

lce 点：

# [  
\Lambda_{\mathrm{lce}}

N+g_{\mathrm{av}}-\frac{P}{2\eta}  
]

# [  
\Lambda_{\mathrm{lce}}

N+g_{\mathrm{av}}-\frac{P}{2\eta}+0.5  
]

同時式・交互式の切り替わり：

- (\Lambda) が整数付近：同時式オフセットが有利
    
- (\Lambda) が半整数付近：交互式オフセットが有利
    
- lce 付近で有利な構造が切り替わる
    

## 話すこと

1リンク2交差点では、(\Lambda) ごとに、オフセット (x) を変えたときの遅れ曲線を理論的に描ける。  
その結果、ある (\Lambda) では適切なオフセットを選べば遅れをほぼゼロにできるが、別の (\Lambda) ではどのオフセットでも遅れが残る。  
前者を hce、後者を lce と呼ぶ。  
また、(\Lambda) が変わると、同時式オフセットが有利な条件と交互式オフセットが有利な条件が切り替わる。

# Slide 11. 多交差点では解析的な足し合わせができない

## 一言でいうと

**2交差点理論は理想的な到着パターンを扱うが、3交差点以上では車群分裂が生じるため、全体遅れは各リンク遅れの和では表せない。**

## スライド内容

左：1リンク2交差点の理想的到着

```text
Intersection i   [ green ]
                 連続した車群
                       \\\\\\\\\
Intersection j          [ green ]
                        まとまって到着
```

右：3交差点以上での分裂

```text
Intersection 0          車群
Intersection 1          [ red ][ green ]
                         一部停止
                         車群が分裂
Intersection 2          分裂して到着
```

式：

[  
d_{\mathrm{route}}\neq d_{01}^{\min}+d_{12}^{\min}+d_{23}^{\min}  
]

理由：

- 前の交差点で停止する
    
- 車群が分裂する
    
- 下流への到着パターンが変わる
    
- 各リンクの理想的到着が同時には成り立たない
    

## 話すこと

1リンク理論では、車群が分裂せずにきれいに下流へ到着するパターンを扱っている。  
しかし多交差点では、途中の信号で赤にかかった車両が止まり、青で再発進するため、車群が分裂する。  
このため、各リンクで計算した理論遅れを単純に足しても、路線全体の遅れにはならない。

---

# Slide 12. 多交差点では累積区間も効く

## 一言でいうと

**個々のリンクが hce でも、複数リンクを合成した区間が lce に近くなることがあり、多交差点の遅れ発生メカニズムは1リンクより複雑である。**

## スライド内容

3リンク4交差点：

[  
0-1-2-3  
]

隣接リンク：

[  
\Lambda_{01},\Lambda_{12},\Lambda_{23}  
]

累積区間：

[  
\Lambda_{02}=\Lambda_{01}+\Lambda_{12}  
]

[  
\Lambda_{13}=\Lambda_{12}+\Lambda_{23}  
]

[  
\Lambda_{03}=\Lambda_{01}+\Lambda_{12}+\Lambda_{23}  
]

例：

```text

Λ12: hce
Λ23: hce

```

## 話すこと

多交差点では、個々のリンクだけでなく、2リンク区間や3リンク区間の位相条件も重要になる。  
個々のリンクが hce に近くても、合成した全体区間が lce に近い可能性がある。  
したがって、多交差点では全区間ペアの (\Lambda) を考慮する必要がある。

# Slide 16. 各区間ペアの位相的な悪さ (r_{ij})

## 一言でいうと

**各区間ペアの (\Lambda_{ij}) が hce 中心からどれだけ離れているかを、lce で区切った区間内の正規化距離 (r_{ij}) として表す。**

## スライド内容

まず、隣り合う lce 点を両端とする区間を考える。

理由：

**lce 付近で同時式オフセットと交互式オフセットが切り替わるため。**

定義：

- (H(\Lambda_{ij}))：その lce–lce 区間内の hce 中心
    
- (B(\Lambda_{ij}))：(\Lambda_{ij}) と同じ側にある lce 境界
    

# [  
r_{ij}

\frac{  
|\Lambda_{ij}-H(\Lambda_{ij})|  
}{  
|B(\Lambda_{ij})-H(\Lambda_{ij})|  
}  
]

意味：

- (r_{ij}=0)：hce 中心
    
- (r_{ij}=1)：lce 境界
    
- 大きいほど系統効果が低い
    

図：

```text
lce boundary       hce center       lce boundary
|---------------------●---------------------|
                      r=0
端に近いほど r=1
```

## 話すこと

単に最寄りの hce 中心から距離を取るだけではなく、lce を境界として区間を区切る。  
これは、lce 付近で同時式・交互式の有利性が切り替わるためである。  
この区間内での正規化距離を (r_{ij}) とし、各区間ペアの位相的な悪さを表す。

# Slide 17. 遅れスケールによる重み (w_{ij})

## 一言でいうと

**同じ (r_{ij}) でも遅れとして効く大きさが異なるため、1リンク理論で得られる最大遅れを用いて重み付けする。**

## スライド内容

背景：

- (r_{ij}) は hce/lce に対する位相的な悪さ
    
- しかし、同じ (r_{ij}) でも、青時間スプリットや需要条件により遅れの出やすさは違う
    
- そこで、1リンク2交差点理論から得られる最大遅れを重みとして用いる
    

重み：

[  
w_{ij}=\frac{d_{ij}^{\max}}{\max d_{ab}^{\max}}  
]

最終的な区間ペア特徴量：

[  
b_{ij}=w_{ij}r_{ij}  
]

今回の重み：

|pair|weight|
|---|--:|
|01|0.82|
|12|0.50|
|23|0.68|
|02|0.68|
|13|0.82|
|03|1.00|

図：

縦軸 (d)、横軸 (x) の曲線を示し、その最大遅れを (d_{ij}^{\max}) として示す。

```text
d
^
|        max
|        ▲
|       / \
|______/   \______
+-----------------> x
```

## 話すこと

ここは伝わりにくい可能性があるので丁寧に説明する。  
1リンク理論では、(\Lambda) ごとにオフセット (x) に対する遅れ曲線を描ける。  
その中で最も遅れが大きくなるスケールを、区間ペアごとの重みとして使う。  
これにより、位相的に悪いだけでなく、実際に遅れとして効きやすい区間を重く評価できる。

# Slide 18. リンク重複なしの分割パターン

## 一言でいうと

**路線全体を重複なく覆う4つの区間分割を考え、それぞれの分割における系統効果の悪さを計算する。**

4つの分割：

[  
S_1=b_{03}

[  
S_2=b_{01}+b_{13}  
]

[  
S_3=b_{02}+b_{23}

[

図：

```text
S1: [0-------------3]

S4: [0--1][1--2][2--3]
```

## 話すこと

全区間ペアをただ足すのではなく、路線全体をリンク重複なしで覆う分割として扱う。

# Slide 19. いくつかの集約指標を試す

## 一言でいうと

**どのように区間ペアの悪さを集約すれば最小遅れをよく説明できるか分からないため、複数の特徴量を比較する。**

## スライド内容

試した特徴量の例：

1. 最悪分割：  
    [  
    S_{\max}=\max(S_1,S_2,S_3,S_4)  
    ]
    
2. 全分割平均：  
    [  
    S_{\mathrm{mean}}  
    ]
    
3. 全分割 RMS：  
    [  
    S_{\mathrm{rms}}  
    =  
    \sqrt{  
    \frac{S_1^2+S_2^2+S_3^2+S_4^2}{4}  
    }  
    ]
    
4. 最悪分割 + 2番目の分割
    
5. 最悪分割 + 非基軸側指標
    

目的：

**どの指標が (d_{\mathrm{opt}}) を最もよく説明するか比較する。**

## 話すこと

最初から (S_{\mathrm{rms}}) と決め打ちしたわけではない。  
最悪の基軸を見る (S_{\max})、全体の悪さを見る平均やRMS、非基軸の悪さを見る指標などを試した。  
その中で、どれが最適遅れをよく説明するかを比較した。

# Slide 20. 分析データと評価指標

## 一言でいうと

**複数路線・複数速度の最適遅れに対して、各特徴量が数値予測と順位付けの両面で有用かを評価する。**

## スライド内容

目的変数：

[  
d_{\mathrm{opt}}\ [s/veh]  
]

評価：

1. 回帰分析
    
    - (R^2)
        
    - RMSE
        
2. 順位評価
    
    - Spearman
        
    - Kendall
        
3. ペア比較
    
    - pairwise accuracy
        

補足：

- 遅れを秒単位で完全に当てるだけでなく、
    
- 候補Aと候補Bのどちらが遅れやすいかを当てることも重要
    

## 話すこと

このモデルは、最終的には候補条件の比較やスクリーニングに使いたい。  
そのため、単に (R^2) だけでなく、順位相関やペア比較の正解率も見る。

# Slide 21. 回帰・順位評価の結果

## 一言でいうと

**速度そのものでは遅れをほとんど説明できない一方、系統効果特徴量は最適遅れを高い説明力で説明した。**

## スライド内容

表：

|モデル|(R^2)|Spearman|Kendall|Pairwise accuracy|
|---|--:|--:|--:|--:|
|speed only|0.073|0.289|0.198|0.603|
|(S_{\max})|0.705|0.798|0.625|0.813|
|(S_{\mathrm{rms}})|0.794|0.877|0.709|0.854|
|(S_{\max}+S_{\mathrm{rms}})|0.795|0.881|0.713|0.857|

## 話すこと

速度そのものでは説明力がかなり低い。  
一方で、(\Lambda) に基づく特徴量を使うと大きく改善する。  
(S_{\max}+S_{\mathrm{rms}}) が最も良いが、次のスライドで示すように多重共線性があるため、単純には解釈できない。

# Slide 22. 多重共線性を考慮した主指標の選択

## 一言でいうと

**(S_{\max}+S_{\mathrm{rms}}) は性能が高いが両者の相関が強いため、解釈しやすさを考えると (S_{\mathrm{rms}}) 単独を主指標とする。**

## スライド内容

結果：

- (S_{\max}+S_{\mathrm{rms}}) は最も高い性能
    
- ただし、  
    [  
    \mathrm{corr}(S_{\max},S_{\mathrm{rms}})\approx 0.95  
    ]
    
- VIF も高い
    
- 係数解釈が不安定
    

したがって、

[  
d_{\mathrm{opt}}\sim S_{\mathrm{rms}}  
]

を主モデル候補とする。

解釈：

[  
S_{\mathrm{rms}}  
]

は、単一の最悪基軸だけでなく、全分割パターンにわたる系統効果の悪さを表す。

## 話すこと

(S_{\max}) は基軸的で分かりやすいが、(S_{\mathrm{rms}}) と非常に強く相関する。  
そのため、両方を入れると性能は少し上がるが、係数の解釈が難しい。  
今回は、解釈性と安定性を重視して (S_{\mathrm{rms}}) 単独を主指標とする。

# Slide 23. 散布図：(S_{\mathrm{rms}}) と (d_{\mathrm{opt}})

## 一言でいうと

**(S_{\mathrm{rms}}) が大きい条件ほど、最適オフセット下でも遅れが大きく残る傾向がある。**

## スライド内容

図：

- 横軸：(S_{\mathrm{rms}})
    
- 縦軸：(d_{\mathrm{opt}})
    
- 点：route-speed
    
- 回帰直線
    

本文：

- (S_{\mathrm{rms}}) が大きいほど遅れが大きい
    
- 決定係数は高いが1ではない
    
- 理由：
    
    - 車群分裂
        
    - 到着パターン変化
        
    - 両方向制約
        
    - キュー形成
        

## 話すこと

この特徴量は、1リンク理論に基づく構造指標であり、多交差点のすべての現象を完全に表すものではない。  
したがって決定係数が1にならないのは自然。  
それでもかなり説明できているため、(\Lambda) 位相条件が遅れの主要因を捉えている可能性がある。

# Slide 24. 候補条件の比較に使えるか

## 一言でいうと

**(S_{\mathrm{rms}}) を使えば、オフセット総当たり計算を行う前に、2つの路線・速度条件のどちらが遅れやすいかを高い確率で判定できる。**

## スライド内容

使い方：

- 候補A：路線A・速度30 km/h
    
- 候補B：路線B・速度40 km/h
    
- (S_{\mathrm{rms}}) を比較
    
- 大きい方を「遅れが出やすい」と判定
    

結果：

[  
\text{pairwise accuracy}=0.854  
]

つまり、任意の2条件を比べたとき、約85%で大小関係を正しく判定。

## 話すこと

このモデルの価値は、秒単位で遅れを完全に当てることだけではない。  
むしろ、候補条件の中でどれが悪そうか、どれが良さそうかを事前に判定できる点にある。  
これは、将来 (C,V,L) の候補を絞るときに使える可能性がある。

# Slide 25. 何に使えるか：(C,V,L) の設計問題へ

## 一言でいうと

**この特徴量は、将来的に速度、サイクル長、交差点間隔を変えたときに遅れが改善する方向かを評価する設計指標として使える。**

## スライド内容

特徴量：

[  
J(C,V,L)=S_{\mathrm{rms}}(C,V,L)  
]

既存路線：

[  
\min_{C,V} S_{\mathrm{rms}}(C,V;L)  
]

交差点配置の変更：

[  
\min_{C,V,L} S_{\mathrm{rms}}(C,V,L)  
]

AI・強化学習への応用：

- (\Lambda_{ij})
    
- (r_{ij})
    
- (b_{ij})
    
- (S_{\mathrm{rms}})
    

を理論特徴量として使う。

## 話すこと

今回は (C) 固定、(L,V) 可変だったが、(\Lambda=L/(CV)) で定義しているため、将来的には (C) の変更にも拡張できる。  
また、交差点配置変更によって (L) が変わる場合にも、この特徴量を使って改善方向を評価できる可能性がある。

# Slide 26. 限界と今後の課題

## 一言でいうと

**今回見ているのは最適オフセット下の最小遅れだけなので、今後は最適解近傍の安定性や良好オフセット範囲も評価する必要がある。**

## スライド内容

今回の対象：

[  
d_{\mathrm{opt}}=\min_x d(x)  
]

つまり、最適オフセット下の性能ポテンシャル。

今後見るべきこと：

- 全オフセットに対する遅れ分布
    
- 最悪遅れ  
    [  
    d_{\max}  
    ]
    
- 良好オフセット率  
$$ 
    p_{\mathrm{good}}=\frac{#{x:d(x)\le d_{\min}+\theta}}{#{x}} 
$$
    
- 最適解近傍の安定性
    
- (C), (L) を変化させた検証
    
- より多交差点への拡張
    

## 話すこと

hceは「良いオフセットが存在する」ことを意味するが、どのオフセットでも良いという意味ではない。  
そのため、今後は最小遅れだけでなく、オフセットを外したときのリスクや、良好オフセット範囲も見る必要がある。

# Slide 27. 結論

## 一言でいうと

**信号遅れはオフセット最適化だけでなく (C,V,L) が作る (\Lambda) 位相構造に強く影響され、(S_{\mathrm{rms}}) はその遅れ低減ポテンシャルを説明する有用な特徴量となり得る。**

## スライド内容

結論：

1. 系統信号制御では、オフセット最適化によって遅れを減らす。
    
2. しかし、最適オフセット下でも、路線や速度によって遅れは大きく異なる。
    
3. 1リンク2交差点では (\Lambda=L/(CV)) とオフセットから遅れを理論的に評価できる。
    
4. 多交差点では車群分裂により単純な足し合わせはできないため、各区間ペアの hce/lce 近接性を特徴量化した。
    
5. リンク重複なし分割に基づく (S_{\mathrm{rms}}) は、最適遅れ (d_{\mathrm{opt}}) をよく説明し、候補条件の順位付けにも有用である可能性がある。
    
6. 今後は (C,V,L) を含めた信号制御・設計問題へ展開する。
    

最後の一言：

**オフセットをどう選ぶかだけでなく、そもそも制御しやすい (C,V,L) 条件を選ぶことが重要である。**
